ProtoxTap V2 Admin Frontend - Change Log

Source and configuration files

- frontend/.gitignore
  Added ignore rules for Vite build output (/dist/) and TypeScript build metadata (*.tsbuildinfo).

- frontend/package.json
  Added the standalone Vite, React, and TypeScript frontend package with dev, build, and preview scripts. Added React Router and the minimal React/Vite/TypeScript dependencies.

- frontend/package-lock.json
  Generated the npm lockfile for the frontend dependencies.

- frontend/index.html
  Added the Vite HTML entry document, viewport metadata, theme color, and page title.

- frontend/vite.config.ts
  Configured Vite and the React plugin. Added a relative /api proxy to the existing backend at http://127.0.0.1:3000 for local development.

- frontend/tsconfig.json
  Added strict TypeScript compiler settings for the frontend.

- frontend/src/main.tsx
  Added the React application entry point, BrowserRouter setup, and global stylesheet import.

- frontend/src/App.tsx
  Added routes for /admin/login, /admin, /admin/businesses, and /admin/cards. Added the authentication guard for admin routes and redirects for the root and unknown paths.

- frontend/src/services/api.ts
  Added typed API functions for login/logout/session checks, business operations, and card operations. Requests use relative URLs and credentials: include; non-success responses surface the backend error message.

- frontend/src/components/AdminLayout.tsx
  Added the authenticated application header, ProtoxTap branding, dashboard/business/card navigation, current username, logout action, and logout error feedback.

- frontend/src/components/StatusBadge.tsx
  Added visual labels for the supported card statuses: Unassigned, Inactive, and Active.

- frontend/src/components/Modal.tsx
  Added a reusable modal shell for business and card forms.

- frontend/src/pages/Login.tsx
  Added the mobile-responsive login page, existing-session check, loading state, login submission, and backend error display. The password is kept only in component state and is cleared after login succeeds.

- frontend/src/pages/Dashboard.tsx
  Added operational counts for businesses, total cards, and each card status, plus a compact card lifecycle overview.

- frontend/src/pages/Businesses.tsx
  Added the business list, responsive desktop table/mobile cards, create and edit form, delete confirmation, and success/error feedback. Lists refresh after changes.

- frontend/src/pages/Cards.tsx
  Added card inventory and status counts, card creation, assignment/reassignment, activation, and deactivation actions. Assignment leaves a card inactive; active cards have no reassignment control. Displays business, review URL, and lifecycle dates.

- frontend/src/styles.css
  Added the responsive admin and login visual styles, form and modal styles, clear status colors, loading/feedback states, and reduced-motion support.

Generated local artifacts

- frontend/node_modules/
  Installed the frontend npm dependencies. This directory is ignored by the root Node ignore rule.

- frontend/dist/
  Generated by the production build and ignored by frontend/.gitignore.

- frontend/tsconfig.tsbuildinfo
  Generated by the TypeScript build and ignored by frontend/.gitignore.

Not changed

- No backend source files or database schema files were modified.
- The Website/ folder was not modified.
